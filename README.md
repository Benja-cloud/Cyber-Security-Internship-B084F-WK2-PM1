# Cyber-Security-Internship-B084F-WK2-PM1
Reconannaisance and Footprinting
Reconnaissance (also called as footprinting) is the first step in any real attack or security test. 
Before touching a target, an attacker quietly collects as much public information about it as possible. 
In this lab, I was able to footprint the live website networkwalks.com using six built-in Kali Linux tools:
- whois 
- whatweb
- nslookup
- curl
- wafw00f
- dnsrecon
I aced the lab but with a few mistakes here and there especially when typing commands.
